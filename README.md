# Диверсификация, операционная эффективность и шок 2022 года

Данные и код к курсовой работе «Диверсификация бизнеса как стратегия управления компромиссом между устойчивостью и эффективностью».

## Содержимое

- `data/Dannye_dlya_kursovoy_2.xlsx` — исходные данные (60 компаний × 2019–2024), без изменений.
- `notebooks/hypothesis_testing_fixed__3_.ipynb` — ноутбук с проверкой гипотез H1 (панельная регрессия с двусторонними FE) и H2 (DiD), без изменений.
- `requirements.txt` — версии библиотек, на которых ноутбук проверялся.

## Как запустить

Ноутбук написан для Google Colab и в ячейке загрузки данных ссылается на файл по пути:

```python
PATH = '/content/Данные для курсовой (2).xlsx'
```

Имя файла в этом пути отличается от имени файла в `data/` (транслитерация). Чтобы запустить ноутбук локально, перед первым запуском нужно один раз отредактировать переменную `PATH` в ячейке раздела «1. Загрузка и очистка данных» на:

```python
PATH = '../data/Dannye_dlya_kursovoy_2.xlsx'
```

Либо переименовать файл в `data/` под путь, ожидаемый ноутбуком. Сам код ноутбука при этом не меняется — правка касается только значения переменной пути.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook notebooks/hypothesis_testing_fixed__3_.ipynb
```

Графики при выполнении ноутбука сохраняются в папку `figures/` рядом с ноутбуком (в `.gitignore`, в репозиторий не входит — воспроизводится запуском кода).
